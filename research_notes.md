# Research notes

The project tests a two-branch concept: MobileNetV2 image-level driver-state classification plus YOLOv8 visible-object detection.

The 1,400 included images are procedurally generated schematic illustrations. They validate software integration, data loading and annotation formats, not real-world accuracy. There is a substantial domain gap to real camera footage. Report held-out metrics only after running evaluation; do not fabricate results. For future real-world work, collect consented diverse recordings and split by driver/session. Drowsiness requires temporal evidence; one image is insufficient. A drink container does not establish alcohol use or impairment.
